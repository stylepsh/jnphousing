# 검색엔진 등록 가이드 — Google + 네이버

도메인 연결(DNS 전파) 완료 후 진행. 두 군데 등록만 끝나면 보통 1~4주 안에 사이트가 검색에 노출되기 시작합니다.

---

## 🟢 1. Google Search Console (구글)

### 등록 절차

1. https://search.google.com/search-console 접속 (Google 계정 로그인)
2. **속성 추가** → **도메인** 탭 선택 (URL 접두어 아님!)
3. `jnphousing.com` 입력 → **계속**
4. 화면에 **TXT 레코드 값** 표시 — 복사
5. 새 탭에서 **가비아 DNS 관리** (`jnphousing.com`) 들어가서:
   - 타입: **TXT**
   - 호스트: `@`
   - 값/위치: (구글이 준 TXT 값 그대로 붙여넣기)
   - TTL: 600
   - 저장
6. 5분 대기 후 Search Console에서 **확인** 클릭 → 초록 ✅

### Sitemap 제출 (가장 중요)

1. Search Console → 좌측 메뉴 **Sitemaps**
2. 입력란에 `sitemap.xml` 입력 → **제출**
3. 우리 사이트의 `/sitemap.xml` 이 자동 인식됩니다 (이미 구현됨)
4. "성공" 상태가 되면 OK → 며칠 안에 페이지 크롤링 시작

### 인덱싱 요청 (선택, 더 빠른 노출)
- 메인 페이지(`/`), `/about`, `/services` 같은 핵심 페이지를 좌측 **URL 검사** 도구에 하나씩 입력
- **색인 생성 요청** 버튼 클릭

## 🟢 2. 네이버 서치어드바이저

> 한국 사용자의 70%가 네이버로 검색합니다. **반드시 등록**.

### 등록 절차

1. https://searchadvisor.naver.com 접속 (네이버 계정 로그인)
2. 우상단 **웹마스터도구** 클릭
3. **사이트 등록** → `https://jnphousing.com` 입력 → 확인
4. 사이트 소유 확인 방법 3가지 중 **"HTML 태그"** 추천:
   - 네이버가 메타 태그 한 줄을 줌 (예: `<meta name="naver-site-verification" content="..." />`)
   - **이 메타 태그를 박성혁님이 코드에 넣어달라고 알려주세요** — 제가 추가해 드립니다
5. 또는 **"DNS"** 방법: 가비아 DNS에 TXT 레코드 추가 (구글 방식과 동일)

### Sitemap 제출
1. 서치어드바이저 → 좌측 메뉴 **요청 → 사이트맵 제출**
2. `sitemap.xml` 입력 → **확인**
3. 며칠 안에 처리됨

### RSS 제출 (선택)
- 우리 사이트는 RSS 없음. 건너뛰기.

### 웹페이지 수집 요청
- 좌측 **요청 → 웹페이지 수집** → URL 하나씩 입력 (메인, 회사소개, 서비스 등)
- 한 번에 50개까지 신청 가능

## 💡 검색 노출을 빠르게 하는 추가 작업

### 1. 네이버 블로그 / 카페에 회사 소개 글 작성
- 회사명을 자연스럽게 언급
- 사이트 URL 링크 포함
- 네이버 검색 알고리즘이 가장 중시

### 2. 카카오맵 / 네이버 지도 등록
- 사업장 위치(부천 중동 팰리스카운티 202-S8호) 등록
- 부장님이 카카오맵·네이버 지도 비즈니스 등록 신청

### 3. 부동산 채널 백링크
- 피터팬·삼삼엠투에 매물 등록 시 사이트 URL 함께 노출
- 부동산 카페에 회사 소개

### 4. 콘텐츠 추가 (선택, 장기)
- /blog 같은 칼럼 페이지 신설
- "HUG 대위변제 대응 방법", "부실 건물 정상화 사례" 같은 실용 글 작성
- 검색 키워드 자연스럽게 포함

---

## ⚠️ 주의사항

- **검색 등록 즉시 = 검색 노출**이 아닙니다. 인내가 필요해요.
- 같은 키워드에 광고비 쓰는 경쟁사가 많으면 자연 검색 상위는 더 오래 걸림.
- **콘텐츠가 충실할수록 빠릅니다** — 회사소개·서비스 설명·실제 관리 현장 정보가 풍부할수록 유리.
