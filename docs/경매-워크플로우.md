# 경매 공실 발굴 워크플로우 (전국한마음자산관리)

> 실제 구현된 시스템 기준. URL은 관리자 로그인 후 접근.
> 큰 그림: **수집 → 발굴 → 답사 → 입력/업로드 → 공실·상품화 → 임대**

---

## 🟦 PART 1. 관리자(나) 진행 순서

### 1단계 — 물건 수집  · `/admin/auction/collection`
- 지지옥션/대법원 검색 결과 텍스트를 붙여넣고 "임포트".
- 자동으로 **채권자가 HUG(주택도시보증공사)·SGI(서울보증보험)인 건만** 수집. 개인·은행 채권은 자동 배제.
- 이미 답사한(공실/점유/재방문) 물건은 **중복 차단**되어 다시 안 들어옴.

### 2단계 — 발굴 (누구를 답사할지)  · 같은 화면
- **지역별 보기**: 지역 카드에서 미답사 건수 확인 → 클릭하면 그 지역 물건. 상단에 **"총 N건 · 페이지 X/Y"** 표시(예: 안산 상록구 249건).
- **임대인별 보기** (상단 "임대인별" 탭): **보유 미답사 ≥1/≥2/≥3** 임대인을 건수순으로. → **물건 많이 깔아둔(운용 안 하는) 임대인**이 핵심 타깃. 임대인 클릭 시 그 사람 **전체 물건**.

### 3단계 — 답사표 만들기  · `/admin/auction/survey`
두 가지 방법:
- **(권장) "답사표 양식 다운로드"** 버튼 → 식별정보(사건번호·주소·임대인)가 **미리 채워진** 엑셀. 답사팀은 빈 칸만 채우면 됨. 지역▸임대인 순 정렬.
- **빈 양식** (`전국한마음자산관리_답사입력_빈양식.xlsx`) → 풀에 없는 즉석 물건용. 사건번호를 손으로 정확히 입력해야 함.
- 종이로 줄 거면 **답사 PDF**(지역▸임대인 정렬)로 출력.

### 4단계 — 답사팀에 전달 → 회수
- 위 양식/PDF를 답사팀에 제공. (PART 2 안내 동봉)
- 답사팀이 현장 다녀와 점유상태 등 기입 후 **엑셀을 나에게 돌려줌**.

### 5단계 — 업로드 (공실/거주 자동 파악)  · `/admin/auction/survey` "답사표 업로드"
- 받은 엑셀을 업로드. **사건번호로 자동 매칭**.
- 자동 분류:
  - **X = 공실** → 상품화 후보(임대가능 라인으로)
  - **O = 점유** → **영구 제외**(다시 수집/답사 안 나옴)
  - **△ = 재방문** → 재방문 목록
- 결과 요약(공실 N·점유 N·재방문 N) 즉시 표시. 배치 **진행률·자동 마감**.

### 6단계 — 공실 상품화  · `/admin/auction/pipeline/vacant`
- 공실 물건 확인(검색: 사건번호/주소/임대인). 단계 이동(승인↔상품화준비↔진행↔임대가능), 작업비 입력.
- **공실 상세 엑셀 / PDF 내보내기**(지역▸임대인, 접기 가능) — 임대인 영업·B팀 작업의뢰용.

### 7단계 — 임대 계약  · `/admin/auction/pipeline/lease-ready`
- 임차 들어오면 보증금·월세·수금일(매월 자유입력)·임차인·기간 입력 → 임대중으로.

### 8단계 — 현황 관리  · `/admin/auction/leases` (임차 현황판)
- KPI: **공실 / 임차중 / 점유제외 / 재방문** 한눈에. 임대 목록(임차인·월세·보증금·수금일).

> 💡 PWA: 크롬에서 "앱 설치" 하면 바탕화면 아이콘 → 경매 파이프라인으로 바로 열리는 프로그램처럼 사용.

## 🟩 PART 2. 답사팀 안내 (이대로 읽으면 이해됨)

**무엇을 받나요?**
전국한마음자산관리 **경매 답사표**(엑셀 또는 종이). 지역 → 임대인 순으로 정리돼 있고, 주소·사건번호·임대인은 이미 적혀 있습니다.

**현장에서 무엇을 하나요?** — 각 물건마다 아래만 채우세요:

| 칸 | 입력 |
|---|---|
| **점유 상태** | **O = 사람 살고 있음(점유)** · **X = 비어있음(공실)** · **△ = 애매/다시 확인 필요(재방문)** |
| 우편 | 우편물 있음 O / 없음 X |
| 계량기 | 확인 O / 미확인 X |
| 개방가능 | 가능 / 불가 / 관리실확인 |
| 현관비번 | 알아낸 비번 (예: #1234#) |
| 관리실 | 관리실 연락처/메모 |
| 비고 | 특이사항(체납영수증, 단전 등) |

**가장 중요한 것**
- **점유 상태(O/X/△)는 반드시** 표시. 이게 공실/거주를 가르는 핵심.
- **X(공실)** 로 표시된 곳이 회사가 **개방·상품화**할 수 있는 대상이 됩니다.
- 사건번호·주소는 **수정하지 말고** 그대로 두세요(식별용).
- (빈 양식일 때만) 맨 윗줄에 **지역명**을 적어주세요.

**끝나면?**
채운 엑셀 파일을 그대로 사무실(관리자)에 전달. → 시스템에 올리면 공실/거주가 자동 집계됩니다.

## 한 줄 요약
수집(HUG·SGI) → 임대인별 발굴(많이 깔아둔 사람) → 답사표 제공 → **점유 O/X/△ 기입** → 업로드 → **X=공실 자동 집계 → 개방·상품화 → 임대**.
