# JNP주택관리 시스템 점검 보고서

**작성일**: 2026-06-11 · **대상**: jnphousing.co.kr 전체 (공개 사이트 47개 화면 + 관리자 OS 68개 화면 + 자동화)
**결론 먼저**: 시스템은 **운영 투입 가능한 상태**입니다. 화면·버튼·계산·DB 저장은 거의 전부 실제로 작동합니다. 다만 **"알림 발송"이 전부 모의(mock) 상태**라는 것이 가장 큰 공백이고, 그 외 업그레이드 항목은 아래 우선순위대로 진행하면 됩니다.

## 2. 🔴 최우선 업그레이드 (운영에 직접 영향)

### 2-1. 알림 발송이 전부 모의(mock) — 가장 큰 공백
- **현상**: 카카오톡·SMS·이메일 발송 코드가 전부 스텁. 만료 임박 알림, 임대인 월간 보고, 부동산 승인 문자, 연체 카톡 안내 버튼 — **화면에는 있지만 실제로는 콘솔에만 찍히고 발송 안 됨**
- **필요한 것**: ① 카카오 비즈메시지(채널 + 발신프로필 + API 키) 또는 ② NCP SENS 문자(키 4개). 키만 넣으면 코드는 준비돼 있음
- **파일**: `src/lib/notify/adapters/kakao.ts`, `sms.ts`

### 2-2. JNP 단기임대 월 정산 자동 생성 누락
- **현상**: 위탁 수수료는 매월 1일 자동 정산되는데, **단기임대(dm) 월 정산은 크론이 없어 매달 수동 입력**해야 함
- **필요한 것**: `/api/cron/monthly`에 dm 정산 자동 생성 추가 (개발 1회)

### 2-3. 운영 환경변수 확인 (Vercel)
- `CRON_SECRET` — 없으면 자동화 4종이 전부 멈춤. **최우선 확인**
- `PII_ENCRYPTION_KEY` — 없으면 계좌번호 암호화가 mock 모드
- 확인법: Vercel → Settings → Environment Variables

### 2-4. 임대인 지급(송금) 기록이 없음
- **현상**: 수수료를 "지급완료"로 표시는 가능하지만, **실제 임대인에게 얼마를 언제 이체했는지** 기록하는 화면이 없음
- **필요한 것**: 소유주별 "지급 기록" (이체일·금액·메모) — 분쟁 방지용

| 3-1 | **계약서에 부동산 경유 정보** | 어느 부동산 통해 계약했는지 + 중개사무소 등록번호 필드 없음. 소개 수수료 추적 불가 |

## 6. 권장 진행 순서 (요약)

1. **Vercel 환경변수 확인** (CRON_SECRET, PII_ENCRYPTION_KEY) — 10분
2. **카카오 비즈 or SENS 키 확보** → 알림 실발송 전환 — 외부 절차
3. **DM 월 정산 크론 + 임대인 지급 기록** — 개발
4. **계약 필드 보강** (부동산 경유·선납/후불) + **상품화 필드** (세대·현관 비밀번호) — 개발
5. PDF 폰트 확인 → 나머지 🟢 항목 순차 진행
